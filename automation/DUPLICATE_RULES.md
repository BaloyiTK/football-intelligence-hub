# Duplicate Rules

Canonical key:
`YYYY-MM-DD|leagueId|normalized-home-team|normalized-away-team`

Before inserting a fixture, check today's file for its fixtureKey.

- Existing fixture: NEVER append a duplicate. Refresh/merge research and model data when newer evidence is better.
- New fixture: append once.
- Team-name spelling differences must be normalized before deciding a fixture is new.
- If kickoff changes, update the existing fixture unless evidence shows it is genuinely a different match.
- Postponed/cancelled status updates the existing fixture.
